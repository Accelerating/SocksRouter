# SocksRouter · SOCKS 路由器

一个 Android SOCKS5 路由工具，通过系统 VPN 接口，将全机或指定应用的网络流量转发到你自己的 SOCKS5 服务器。

## 主要功能

- **路由模式**：支持「全局代理」「仅代理已选择的应用」和「仅直连已选择的应用」。全局代理无需选择应用，忽略已有应用选择；路由器自身直连以避免代理循环。
- **服务器配置**：保存多个 SOCKS5 服务器配置，手动选择当前使用的服务器。
- **DNS 设置**：支持 DNS-over-HTTPS（DoH）、自定义 DNS、系统 DNS，以及 DNS 缓存和回退策略。
- **局域网直连**：可选择让局域网流量直接连接。
- **连接状态与诊断日志**：查看代理运行状态和错误信息。

## 下载与使用

从 [GitHub Releases](https://github.com/Accelerating/SocksRouter/releases) 下载 APK。当前支持 **Android 12 及以上、arm64-v8a 设备**。

1. 添加可访问的 SOCKS5 服务器，填写 IPv4 地址和端口。
2. 选择「全局代理」，或选择按应用分流模式及需要代理或直连的应用。
3. 点击「启动代理」，并允许系统 VPN 连接请求。

需要自行准备 SOCKS5 服务器；当前支持无需用户名和密码认证的服务器。
